# Fetal Monitor PCB Reverse Engineering

## Project Overview

This project involved analyzing an existing printed circuit board (PCB) from a fetal monitoring device and reconstructing its circuit schematic using Altium Designer.

The work focused on understanding the board's electronic architecture through physical inspection, component identification, and circuit analysis.

## My Contribution

- Inspected the physical PCB and its electronic components.
- Analyzed component connections and circuit interconnections.
- Reconstructed the circuit schematic in Altium Designer based on the physical board.

## Tools & Skills

- Altium Designer
- Electronic Circuit Analysis
- PCB Inspection
- Schematic Reconstruction
- Hardware Reverse Engineering

## Project Scope

This project reflects practical experience in analyzing existing medical-device electronics and documenting circuit designs from physical hardware.

The work focused on reverse engineering an existing board rather than designing the original device from scratch.
